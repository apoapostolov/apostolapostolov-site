# Apostol Apostolov — Personal Presence

A clean, responsive placeholder site for Apostol Apostolov. It is intentionally small and static so it can be deployed directly to Cloudflare Pages with no build command.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Cloudflare Pages

Create a Pages project connected to this GitHub repository with:

- **Production branch:** `main`
- **Build command:** none
- **Build output directory:** `/`

The site is ready for the placeholder content to be replaced with final biography, work history, projects, and contact links.

## Structure

- `index.html` — semantic page structure and placeholder content
- `styles.css` — responsive visual system and layout
- `.gitignore` — common local/editor exclusions
